## Общие правила

- Фон кремовый `#FEF9F6`, карточки мятные/тёплые/розовые, крупные скругления 20–24 px.
- Тени почти не используются — иерархия строится цветом фона и скруглениями.
- Кнопки — pill-формы на всю ширину; пара «контурная + заполненная» снизу экрана челленджа.
- Строка задачи: кружок-чекбокс 24 px, заголовок, необязательная серая подпись, необязательная квадратная миниатюра справа.
- Зона нажатия не меньше 44 px.

## Чего в макетах нет

- **Desktop-раскладка** — по решению заказчика делаем полноценный адаптив с боковым меню.
- Экраны входа, регистрации, сброса пароля, профиля.
- Пустые состояния, состояния загрузки и ошибок.
- **Тёмная тема** — нужна по решению заказчика, значения подбираются отдельно (см. `web/app/assets/css/tokens.css`).
